

# Architecture
- Keep TanStack Start file-based routing; route files own metadata and compose focused components to preserve code splitting.
- Centralize editable temple information in typed content modules; unknown values stay null so pages cannot imply verification.
- Render one shared header and footer in the root layout; homepage sections live in separate modules to preserve the existing design.
- Use standard open-source Vite and TanStack plugins for independent deployment; do not reintroduce platform runtime SDKs.
